# Public Safety

CarbonOps-Parser should be described with careful, bounded language. The project is a documentation-first technical artifact for scheduled carbon factor ingestion and source-aware parsing.

## Wording To Avoid

Avoid language that implies:

- Readiness for production use.
- Enterprise or bank-level assurance.
- Readiness for regulated reporting.
- Certification or legal assurance.
- Guaranteed security.
- Verified carbon inventory calculation.
- Official emissions report generation.
- Official calculation status.
- Personal-status, external-approval, or talent-program positioning.

## Preferred Wording

Use wording such as:

- Scheduled carbon factor ingestion.
- Source-aware emission factor parsing.
- Documentation-first technical artifact.
- Non-production reference implementation.
- Background ingestion reference.
- Python and .NET implementation options.
- PostgreSQL-backed ingestion metadata.
- Source-specific master/detail tables.

## Positioning Notes

CarbonOps-Parser is independent from `carbonops-assistant`.

The project should not be described as a calculation engine, reporting tool, replacement for source-owner documentation, or deployment platform.
