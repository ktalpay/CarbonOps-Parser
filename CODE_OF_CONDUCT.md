# Code of Conduct

CarbonOps-Parser is a small public reference project. Contributors, maintainers, and participants are expected to keep discussion respectful, practical, and focused on improving the project.

## Expected Behavior

- Be considerate and constructive.
- Assume good intent while asking clarifying questions.
- Keep feedback focused on documentation, examples, source discovery, parser mappings, database design, and implementation quality.
- Avoid sharing confidential data, private source files, credentials, or personal information.

## Unwelcome Behavior

- Harassment, threats, or personal attacks.
- Repeated off-topic comments.
- Sharing confidential or private data.
- Misrepresenting the project scope or claims.

## Reporting

If a discussion needs maintainer attention, open an issue with relevant context or use the repository contact path listed by the project owner. Do not include confidential information in public reports.
